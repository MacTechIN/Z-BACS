# ADR-0004: 프록시 재암호화(PRE)/임계값 위임은 Phase 3로 연기

- 상태: Accepted (2026-09-18)

## 컨텍스트
타당성 보고서는 NuCypher Umbral/TACo 또는 Lit Protocol 기반 PRE를 핵심축으로 제안했다. 그러나 2026-09 기준 NuCypher 조직은 비활성이며 TACo는 WEDF 재출범 대기 상태이고, Lit v8/Naga는 유료 운영 네트워크다. 또한 프로젝트 정의의 핵심 흐름은 **소유자가 실시간으로 승인**하는 것이므로 승인 시점에 소유자 기기가 온라인이다.

## 결정
- MVP(Phase 1~2)는 승인 시점에 소유자 Agent/승인 앱이 DEK를 수신자 기기 공개키로 HPKE 봉투화하여 전달한다. PRE 불필요.
- Phase 3에서 "소유자 오프라인 시 정책 기반 자동 위임"을 위해 (a) `umbral-pre` 기반 자체 Guardian 노드 또는 (b) Lit v8 중 택일한다. 결정 시 GPL 격리·비용·WEDF TACo 상태를 재평가한다.

## 근거
- 외부 네트워크 의존 없이 동일한 보안 속성(승인 없이는 개봉 불가)을 달성한다.
- 유지보수 중단 라이브러리에 MVP를 걸지 않는다.

## 결과
- 소유자 승인 앱은 DEK를 복원할 수 있어야 한다 → 소유자 봉인키를 승인 앱(모바일)에도 안전하게 동기화하거나, 데스크톱 Agent가 승인 앱의 서명을 받아 봉투를 만든다(MVP: 후자).

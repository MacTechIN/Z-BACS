# Z-BACS 사용 안내 (테스트 참가자용)

| 문서 버전 | 1.0 (2026-09-29, Z-1.D.1) |
|---|---|
| 대상 | 닫힌 베타 참가자. 이 글은 설명서라기보다 "이렇게 하면 됩니다"이며, **읽지 않아도 쓸 수 있어야 정상**입니다. 읽어야만 되는 부분이 있었다면 그것이 버그이니 알려 주세요 |
| 걸리는 시간 | 설치 2분, 처음 켤 때 30초, 그 뒤로는 파일 하나에 몇 초 |

## 한눈에

- 파일을 **잠그면** 원래 파일 옆에 `이름.zbacs`가 생깁니다. 이것을 보내면 됩니다.
- 받은 사람이 그 파일을 열면 **주인에게 물어보고**, 주인이 **허락**하면 열립니다. 허락은 "읽기만" 또는 "편집도 가능" 둘 중 하나이고, 시간이 지나면 저절로 끝납니다.
- 편집을 허락받은 사람이 저장하면 파일은 **저절로 다시 잠기고** 주인에게 알려집니다.
- 주인은 언제든 **허락을 거둘** 수 있습니다. 거두면 상대 쪽 파일은 바로 닫힙니다.
- 무엇이 언제 있었는지는 **기록**에서 봅니다.

비밀번호, 계정 만들기, 서버 주소, 설정 화면은 없습니다. 있어야 하는 것처럼 보이면 알려 주세요.

## 1. 설치하기 (Windows)

1. 받은 링크에서 `Z-BACS_…_x64-setup.exe`를 내려받아 두 번 누릅니다.
2. 파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 아직 서명이 없는 테스트 버전이라 한 번 뜹니다.
3. 설치가 끝나면 Z-BACS 창이 열립니다. 작업 표시줄 오른쪽(시계 옆)에 작은 아이콘이 생기고, 창을 닫아도 거기 남아 있습니다. 허락 요청을 받으려면 거기 있어야 하니 **종료하지 마세요**(종료는 그 아이콘의 오른쪽 클릭 메뉴에만 있습니다).

내 PC가 되는지 먼저 보고 싶다면 같은 곳에 있는 `zbacs-wincheck.exe`를 두 번 누르세요. 2분쯤 검사하고 결과를 보여 줍니다. 중간에 Windows 얼굴·지문·PIN 창이 두 번 뜹니다. 빨간 줄이 있으면 창 내용을 그대로 복사해서 보내 주세요.

## 2. 처음 켤 때 — 두 번만 누르기

1. [시작하기]
2. 허락하는 방법을 고릅니다.
   - **얼굴이나 지문으로 확인하고 허락** — 허락할 때마다 Windows Hello 창이 뜹니다. 권장.
   - **이 컴퓨터에서 바로 허락** — 버튼만 누르면 됩니다. 편집 허락처럼 중요한 것은 그래도 한 번 더 확인합니다.
   이 컴퓨터에서 쓸 수 없는 방법은 버튼이 눌리지 않고 이유가 한 줄 적혀 있습니다.
3. "준비하고 있어요" 뒤에 준비가 끝납니다. 끝. 입력할 것은 없습니다.

아래 두 문장 중 하나가 보일 수 있습니다. 쓰는 데는 문제가 없고, 알고 계시라는 뜻입니다.
- "이 컴퓨터에는 전용 보안 칩이 없어요." — 보호가 조금 약합니다.
- "이 컴퓨터에는 안전한 보관함이 없어서, 앱을 다시 켜면 준비를 한 번 더 해야 해요."

## 3. 파일 잠그기 (보내는 사람)

1. 창 어디에든 파일을 끌어다 놓거나 [파일 고르기]를 누릅니다. 폴더는 아직 안 됩니다.
2. 받는 사람이 어디까지 할 수 있게 할지 고릅니다: [읽기만] 또는 [편집 허용]. 기본은 읽기만입니다.
   [고급]을 열면 허락이 얼마나 오래 가는지(1시간·하루·1주)와 몇 번 열 수 있는지(한 번·세 번·제한 없음)를 고를 수 있습니다. 안 열어도 됩니다.
3. [잠그기]. 원래 파일 옆에 `이름.zbacs`가 생깁니다.
4. 결과 화면이 **원본은 아직 그대로**라고 말해 줍니다. 원본을 없애려면 거기서 [원본 지우기]를 두 번 확인합니다. 그냥 두어도 됩니다.
5. `이름.zbacs`를 평소처럼 보냅니다 — 메일, 메신저, USB, 어디로든. 이 파일은 잠겨 있어서 중간에 누가 보아도 내용을 알 수 없습니다.

같은 이름으로 이미 잠근 파일이 있으면 덮어쓰지 않고 멈춥니다. 옮기거나 지운 뒤 다시 하세요.

## 4. 받은 파일 열기 (받는 사람)

1. `이름.zbacs`를 두 번 누릅니다. Z-BACS가 깨어나 카드 하나를 보여 줍니다: 잠긴 파일이라는 것, 몇 번째 판인지, 주인이 기본으로 어디까지 허락했는지.
2. [주인에게 물어보기]. "주인의 허락을 기다리는 중…"이 돕니다. 창을 닫아도 계속 기다립니다.
   - 2분이 지나면 "아직 답이 없어요"로 바뀌지만 계속 기다립니다. 5분이 지나면 멈추고 [다시 물어보기]가 보입니다.
   - "지금은 연결할 수 없어요"가 뜨면 인터넷 연결을 확인하고 다시 누릅니다.
3. "허락받았어요"가 뜨면 [열기]. 파일 종류에 맞는 프로그램(메모장·Word·PDF 등)이 열립니다. 그동안 화면에는 열린 자물쇠와 **남은 시간**이 보입니다.
4. 다 봤으면 프로그램을 평소처럼 닫습니다. 또는 화면의 [지금 잠그기]. 어느 쪽이든 파일은 다시 잠기고 풀린 내용은 컴퓨터에 남지 않습니다.

읽기만 허락받았으면 프로그램에서 저장이 되지 않거나, 다른 이름으로 저장하라고 합니다. 그렇게 저장한 사본은 잠기지 않은 파일이니 만들지 마세요.

## 5. 편집하고 저장하기 (편집 허락을 받았을 때)

평소처럼 고치고 **저장**하면 됩니다. 저장하는 순간 카드가 "다시 잠그는 중"이 되었다가 "열림"으로 돌아오고, "저장한 내용을 다시 잠갔고 주인에게 알렸어요"가 보입니다. 따로 할 일은 없습니다.

저장한 뒤의 파일은 **새 판**입니다. 다음에 누가 열려면 다시 물어봐야 하고, 주인은 새 판을 그대로 허락할 수 있습니다(주인에게 파일을 다시 보낼 필요 없음).

## 6. 허락하기 (주인)

누가 물어보면 세 가지 중 하나로 알게 됩니다.

- **오른쪽 아래 알림**: "누군가 내 파일을 열려고 해요 — 『이름』 파일을 읽기만 하고 싶어 해요" + [읽기만 허락] [편집도 허락] [거절] [앱에서 보기]. 알림에서 바로 누르면 끝입니다.
- **창이 앞으로 옴**: 알림을 꺼 두었으면 Z-BACS 창이 앞으로 와서 같은 것을 보여 줍니다.
- **나중에**: 자리를 비웠으면 돌아왔을 때 창에 요청이 쌓여 있습니다(하루 안의 것만).

화면에 보이는 파일 이름은 **내 컴퓨터가 잠근 기록**에서 가져온 것이라, 모르는 파일이나 그 뒤로 바뀐 판에 대한 요청은 [거절]만 있습니다. 그런 요청이 오면 무언가 이상한 것이니 알려 주세요.

[편집도 허락]은 항상 얼굴·지문·PIN 확인을 거칩니다. "이 컴퓨터에서 바로 허락"을 골랐고 이 컴퓨터에 Hello가 없으면 [편집도 허락] 버튼 자체가 보이지 않습니다 — 읽기만 허락할 수 있습니다.

허락은 잠글 때 정한 시간(기본 1시간) 동안만 갑니다. 그 뒤엔 상대가 다시 물어봐야 합니다.

## 7. 허락 거두기 (주인)

홈의 [내가 허락한 파일]에 지금 살아 있는 허락이 보입니다 — 파일 이름, 읽기만/편집, 남은 시간. [허락 거두기]를 누르면 "허락을 거뒀어요". 상대가 파일을 열어 두고 있었다면 몇 초 안에 그쪽 프로그램이 닫히고 "주인이 허락을 거뒀어요"가 뜹니다.

## 8. 기록

홈의 [기록]에 이 컴퓨터에서 있었던 일이 최근 순으로 쌓입니다: 잠금, 요청, 허락, 거절, 거둠, 열람, 끝남, 문제. 위의 칩으로 종류만 골라 볼 수 있습니다. 시각 옆에 "· 확인됨"이 붙은 줄은 공개 기록에서도 확인된 것입니다.

기록에는 파일 이름과 무슨 일이 있었는지만 있습니다. 파일 내용이나 상대가 누구인지는 없습니다.

## 9. 문제가 생기면

모든 문제 화면은 한 문장과 다음에 누를 버튼 하나로 되어 있습니다. 자주 보게 될 것들:

| 화면의 말 | 뜻 | 할 일 |
|---|---|---|
| 지금은 연결할 수 없어요 | 인터넷이 끊겼거나 서버가 잠시 답이 없음 | 연결 확인 후 [다시 물어보기] |
| 주인이 아직 답하지 않았어요 | 5분 동안 답이 없었음 | [다시 물어보기]. 주인에게 직접 말해도 됩니다 |
| 받은 답이 이 파일과 맞지 않아요 | 다른 파일·다른 판·다른 컴퓨터용 허락이 왔음 | [다시 물어보기]. 반복되면 알려 주세요 |
| 그 뒤로 파일이 바뀌어서 이 요청은 허락할 수 없어요 | 상대가 옛 판을 들고 있음 | 거절하고, 상대가 새 판을 받아 다시 물어보게 |
| 파일이 손상되었거나 읽을 수 없어요 | 보내는 중에 깨졌거나 잠긴 파일이 아님 | 보낸 사람에게 다시 받기 |
| 더 새로운 방식으로 잠긴 파일이에요 | 내 Z-BACS가 오래됨 | 새 설치 파일로 다시 설치 |
| 편집 허락은 얼굴·지문·PIN 확인이 필요한데… | 이 컴퓨터로는 편집 허락을 못 함 | 읽기만 허락하거나, Windows에 PIN을 등록한 뒤 다시 준비 |
| …하지 못했어요. 잠시 뒤 다시 시도해 주세요 | 그 밖의 문제 | [다시 시도]. 반복되면 아래 "보내 주실 것" |

## 10. 이 테스트 버전에서 알아 두실 것

- 설치할 때 "PC 보호" 창이 한 번 뜹니다(서명이 아직 없습니다).
- 프로그램이 파일을 열고 있는 동안 컴퓨터를 끄거나 Z-BACS를 종료하면, 다음에 켰을 때 그 파일은 다시 물어봐야 합니다. 풀린 내용은 남지 않습니다.
- 파일 종류에 따라 프로그램 종료를 알아채지 못할 때가 있습니다. 그때는 [지금 잠그기]로 끝내 주시고, 어떤 프로그램이었는지 알려 주세요.
- 폴더는 아직 잠글 수 없습니다.

## 보내 주실 것

무엇이든 막히면 아래 셋을 보내 주세요. 파일 내용은 보내지 않아도 됩니다.
1. 어느 화면에서, 무엇을 눌렀고, 무슨 문장이 나왔는지 (스크린샷이면 더 좋습니다)
2. 처음 켤 때 고른 방법(얼굴·지문 / 이 컴퓨터에서 바로)
3. `zbacs-wincheck.exe` 결과에 빨간 줄이 있었다면 그 내용

고맙습니다. 이 글을 읽어야만 되는 부분이 있었다면 그것도 알려 주세요 — 그 부분을 없애는 것이 목표입니다.

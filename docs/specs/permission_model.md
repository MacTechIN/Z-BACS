# 스펙: 권한 모델 v1

| 권한 | 복호화 | 저장(재봉인) | 작업공간 속성 | 세션 종료 시 |
|---|---|---|---|---|
| **Deny** | 불가 | - | - | 거부 사유 표시, `Denied` 로그 |
| **ReadOnly** | 가능 | 변경분 폐기 | 읽기전용 ACL, 변경 감지 시 경고 | 평문 삭제, `Opened` 로그 |
| **Edit** | 가능 | 새 버전으로 재봉인 | 읽기/쓰기 | 재봉인 → 평문 삭제, `Sealed` 로그, 소유자 알림 |

## 조건(Constraints)
| 조건 | 설명 | 기본값 |
|---|---|---|
| `ttl` | 승인 후 세션 유효 시간 | 3600s |
| `maxOpens` | 동일 승인으로 열 수 있는 횟수 | 1 |
| `devicePin` | 승인 시 지정된 기기에서만 개봉 | true |
| `strict` | 온체인 확정 확인 필수 | false (기업 정책은 true) |
| `watermark` | 열람 화면/문서에 수신자 식별 워터마크(2단계) | false |

## 확장 예정(권한 비트)
`print`, `copy`, `export` 등은 미니필터/앱 통합 없이는 강제 불가 → Phase 3에서 정의. 1단계에서는 정책에 기록만 하고 UI로 고지한다.

## 편집 후 버전 정책
- 새 버전은 소유자 봉투로 봉인되므로 소유자는 승인 없이 열 수 있다.
- 수신자는 자신이 만든 새 버전도 재승인 필요(정책 옵션 `authorRetainsAccess`로 완화 가능, 기본 false).
- 소유자에게 "새 버전 v(N+1) 생성" 알림 + diff 해시.

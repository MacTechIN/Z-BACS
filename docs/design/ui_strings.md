# UI 문자열 사전과 금지 용어 (Z-1.U.2)

| 문서 버전 | 1.0 (2026-09-21) |
|---|---|
| 지위 | [ux_principles.md](../ux_principles.md) §3.3(기술 용어 금지)·§5(U-5, U-6)의 집행 규칙 |
| 검사 도구 | `tools/ux-lint.sh` (CI `ux` 잡에서 실행) |

## 1. 이 문서가 하는 일

UI에 쓰는 말을 한곳에 모으고, **금지 용어가 화면에 들어가는 것을 CI에서 막는다.** 아래 §3의 목록이 곧 린트의 입력이다(스크립트가 이 문서를 읽는다). 용어를 추가·삭제할 때는 이 표만 고치면 된다.

검사 대상은 `apps/*/ui/*.{html,js,css}`와 `apps/*/src-tauri/src/*.rs`이며, **한글이 들어 있는 줄만** 본다. 프로젝트 규칙 7(코드 주석은 영어)이 있으므로 한글 = 사용자에게 보이는 문구다.

## 2. 쓰는 말 / 쓰지 않는 말

| 개념 | UI에 쓰는 말 | 쓰지 않는 말 |
|---|---|---|
| 봉인 | 잠그기, 잠긴 파일 | 암호화, 봉인(container), AEAD |
| 개봉 | 열기, 열람 | 복호화, 개봉 |
| 승인 | 허락, 승인, 읽기만, 편집 허용 | 권한 부여, 티켓, 그랜트 |
| 소유자 | 주인, 보낸 사람 | 소유자 계정, 오너 |
| 기기 | 이 컴퓨터, 내 기기 | 디바이스, 노드, 엔드포인트 |
| 인증 | 얼굴·지문으로 확인 | 생체인증, 패스키, WebAuthn, FIDO |
| 기록 | 기록 | 체인, 원장, 트랜잭션 |
| 준비 | 준비하고 있어요 | 등록, 프로비저닝, 초기화 |
| 보관 | 안전한 보관함 | 키 저장소, 키체인, TPM |

문장 규칙(올리브 가이드에서 채택): 주어는 "파일"과 "사람", 한 문장 한 뜻, 본문 16px 이상, 색만으로 상태를 전달하지 않는다.

## 4. 텍스트 입력 금지 (U-6)

온보딩·봉인·승인·열람 흐름에는 `<input>`, `<textarea>`, `contenteditable`이 없어야 한다. 린트가 UI 파일 전체에서 이 세 가지를 찾아 실패시킨다. 예외가 필요하면(파일명 바꾸기 등) 먼저 [ux_principles.md](../ux_principles.md) §3.2를 고친다.

## 5. 토큰 검사 (CLAUDE.md 규칙 8)

린트는 UI 스타일시트가 쓰는 모든 `var(--zb-*)`가 `packages/design-tokens/tokens.css`에 실제로 있는지, 그리고 UI에 **직접 쓴 색(#rrggbb)이나 px 값이 없는지** 확인한다.

## 6. 실행

```
tools/ux-lint.sh          # 저장소 루트에서
```

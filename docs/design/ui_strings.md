# UI 문자열 사전과 금지 용어 (Z-1.U.2)

| 문서 버전 | 1.1 (2026-09-23: §7 오류 카탈로그, Z-1.U.4) |
|---|---|
| 지위 | [ux_principles.md](../ux_principles.md) §3.3(기술 용어 금지)·§5(U-5, U-6)의 집행 규칙 |
| 검사 도구 | `tools/ux-lint.sh` (CI `ux` 잡에서 실행) |

## 1. 이 문서가 하는 일

UI에 쓰는 말을 한곳에 모으고, **금지 용어가 화면에 들어가는 것을 CI에서 막는다.** 아래 §3의 목록이 곧 린트의 입력이다(스크립트가 이 문서를 읽는다). 용어를 추가·삭제할 때는 이 표만 고치면 된다.

검사 대상은 `apps/*/ui/*.{html,js,css}`와 `apps/*/src-tauri/src/*.rs`이며, **한글이 들어 있는 줄만** 본다. 프로젝트 규칙 7(코드 주석은 영어)이 있으므로 한글 = 사용자에게 보이는 문구다.

## 2. 쓰는 말 / 쓰지 않는 말

| 개념 | UI에 쓰는 말 | 쓰지 않는 말 |
|---|---|---|
| 봉인 | 잠그기, 잠긴 파일 | 암호화, 봉인(container), AEAD |
| 개봉 | 열기, 열람 | 복호화, 개봉 |
| 승인 | 허락, 승인, 읽기만, 편집 허용 | 권한 부여, 티켓, 그랜트 |
| 소유자 | 주인, 보낸 사람 | 소유자 계정, 오너 |
| 기기 | 이 컴퓨터, 내 기기 | 디바이스, 노드, 엔드포인트 |
| 인증 | 얼굴·지문으로 확인 | 생체인증, 패스키, WebAuthn, FIDO |
| 기록 | 기록 | 체인, 원장, 트랜잭션 |
| 준비 | 준비하고 있어요 | 등록, 프로비저닝, 초기화 |
| 보관 | 안전한 보관함 | 키 저장소, 키체인, TPM |

문장 규칙(올리브 가이드에서 채택): 주어는 "파일"과 "사람", 한 문장 한 뜻, 본문 16px 이상, 색만으로 상태를 전달하지 않는다.

## 4. 텍스트 입력 금지 (U-6)

온보딩·봉인·승인·열람 흐름에는 `<input>`, `<textarea>`, `contenteditable`이 없어야 한다. 린트가 UI 파일 전체에서 이 세 가지를 찾아 실패시킨다. 예외가 필요하면(파일명 바꾸기 등) 먼저 [ux_principles.md](../ux_principles.md) §3.2를 고친다.

## 5. 토큰 검사 (CLAUDE.md 규칙 8)

린트는 UI 스타일시트가 쓰는 모든 `var(--zb-*)`가 `packages/design-tokens/tokens.css`에 실제로 있는지, 그리고 UI에 **직접 쓴 색(#rrggbb)이나 px 값이 없는지** 확인한다.

## 6. 실행

```
tools/ux-lint.sh          # 저장소 루트에서
```

## 7. 오류 카탈로그 (Z-1.U.4)

규칙(ux_principles 규칙 6): **모든 오류는 한 문장 + 다음 행동 버튼**이다. 백엔드는 아래 첫 열의 기계값만 돌려주고, 문장은 `apps/agent/ui/app.js`의 `*_PROBLEMS` 표에, 버튼은 그 화면에 있다. 세 곳이 어긋나면 사람이 빈 줄을 보게 되므로 두 검사가 막는다: `tools/ux-lint.sh`(이 표 ↔ app.js), `apps/agent/src-tauri/tests/errors.rs`(백엔드 상수 ↔ app.js ↔ 이 표).

같은 기계값이 여러 흐름에서 나올 수 있다(`failed`, `not_set_up`, `relay_unreachable`…). 문장은 흐름마다 조금 달라도 되지만, **다음 행동은 같아야** 한다.

<!-- ux-lint:errors:start -->
| 기계값 | 어디서 | 문장(요지) | 다음 행동(버튼) |
|---|---|---|---|
| `not_sealed` | 파일 카드 | 잠긴 파일이 아니에요 | [이 파일 잠그기] → 잠그기 화면 |
| `newer_version` | 파일 카드 | 더 새로운 방식으로 잠긴 파일이에요. 앱을 업데이트해 주세요 | [목록에서 지우기] |
| `missing` | 파일 카드·잠그기·요청 | 그 파일을 찾을 수 없어요 | [목록에서 지우기] / [파일 고르기] / [확인] |
| `damaged` | 파일 카드 | 파일이 손상되었거나 읽을 수 없어요. 보낸 사람에게 다시 받아 주세요 | [목록에서 지우기] |
| `cancelled` | 첫 실행·허락 | 확인이 취소됐어요. 다시 눌러 주세요 | [다시 시도] / [확인] |
| `unsupported` | 첫 실행 | 이 방법은 이 컴퓨터에서 쓸 수 없어요. 다른 방법을 골라 주세요 | [다시 시도] → 선택 화면 |
| `no_signer` | 첫 실행 | 이 컴퓨터에서는 아직 지원하지 않는 방식이에요 | [다시 시도] |
| `failed` | 모든 흐름 | …하지 못했어요. 잠시 뒤 다시 시도해 주세요 | [다시 시도] / [다시 물어보기] / [확인] |
| `is_folder` | 잠그기 | 폴더는 아직 잠글 수 없어요. 파일 하나를 골라 주세요 | [파일 고르기] |
| `already_locked` | 잠그기 | 이 파일은 이미 잠겨 있어요 | [파일 고르기] |
| `empty` | 잠그기 | 빈 파일이에요. 내용이 있는 파일을 골라 주세요 | [파일 고르기] |
| `output_exists` | 잠그기 | 같은 이름으로 잠근 파일이 이미 있어요. 옮기거나 지운 뒤 다시 | [파일 고르기] |
| `unreadable` | 잠그기·요청 | 그 파일을 읽을 수 없어요 | [파일 고르기] / [확인] |
| `not_set_up` | 잠그기·요청·허락·거두기 | 먼저 준비를 마쳐야 해요 | [확인] → 첫 실행 |
| `no_locked_copy` | 잠근 뒤 원본 지우기 | 잠근 파일이 옆에 없어서 원본을 지우지 않았어요 | [완료] |
| `relay_unreachable` | 요청·허락·거두기 | 지금은 연결할 수 없어요. 인터넷 연결을 확인하고 다시 시도해 주세요 | [다시 물어보기] / [확인] |
| `relay_refused` | 요청 | 이 컴퓨터를 아직 받아 주지 않았어요. 앱을 껐다 켠 뒤 다시 | [다시 물어보기] |
| `owner_denies` | 요청 | 주인이 이 파일을 아무도 열 수 없게 잠가 두었어요 | (버튼 없음 — 카드에 표시, 요청 불가) |
| `already_asking` | 요청 | 이 파일은 이미 물어보는 중이에요 | [확인] → 대기 화면 |
| `mismatch` | 요청 | 받은 답이 이 파일과 맞지 않아요. 주인에게 다시 물어봐 주세요 | [다시 물어보기] |
| `window` | 요청 | 허락은 받았지만 지금은 쓸 수 없는 시간이에요 | [다시 물어보기] |
| `unknown_file` | 허락 | 이 컴퓨터에서 잠근 파일이 아니라서 허락할 수 없어요 | [거절]만 표시 |
| `version` | 허락 | 그 뒤로 파일이 바뀌어서 이 요청은 허락할 수 없어요 | [거절]만 표시 |
| `file_moved` | 허락 | 잠근 파일을 찾을 수 없어요. 원래 자리로 되돌린 뒤 다시 | [확인] |
| `not_mine` | 허락 | 이 파일은 내가 잠근 파일이 아니에요 | [확인] |
| `needs_os_confirm` | 허락(편집) | 편집 허락은 얼굴·지문·PIN 확인이 필요한데 이 컴퓨터에는 준비돼 있지 않아요 | [읽기만 허락] 남김 / 화면·알림에서 [편집도 허락]을 아예 보이지 않음 |
| `unknown_request` | 허락 | 이 요청은 이미 처리됐어요 | [확인] → 목록 갱신 |
| `unknown_grant` | 거두기 | 이 허락은 이미 지난 것이에요 | [확인] → 목록 갱신 |
<!-- ux-lint:errors:end -->

새 기계값을 추가하는 순서: ① 백엔드 모듈의 `*_PROBLEMS` 상수 ② `app.js`의 해당 `*_PROBLEMS` 표에 문장 ③ 이 표에 행 + 버튼. 셋 중 하나가 빠지면 `cargo test --features demo-signer`(errors.rs) 또는 `tools/ux-lint.sh`가 실패한다.

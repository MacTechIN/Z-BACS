## 설치하기

1. 아래 **Assets**에서 `Z-BACS_…_x64-setup.exe`를 내려받아 두 번 누릅니다.
2. 파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. (아직 서명이 없는 테스트 버전이라 한 번 뜹니다.)
3. 설치가 끝나면 화면이 시키는 대로 두 번만 누르면 준비가 끝납니다.

사용 방법은 `docs/user_guide.md`에 있습니다 — 읽지 않아도 쓸 수 있어야 정상이고, 읽어야만 되는 부분이 있었다면 알려 주세요.

## 내 PC가 맞는지 먼저 보고 싶다면

`zbacs-wincheck.exe`를 두 번 누르면 약 2분 동안 검사하고 결과를 보여 줍니다. 중간에 Windows 얼굴·지문·PIN 창이 두 번 뜹니다. 빨간 줄이 있으면 창 내용을 그대로 복사해서 보내 주세요.

## 이 버전에서 되는 것

파일 잠그기, 잠근 파일을 받은 사람이 주인에게 물어보기, 알림에서 바로 허락·거절, 열어 보기, 편집 허락이면 저장 시 저절로 다시 잠그기, 허락 거두기, 기록 보기. 두 대의 PC 사이에서 됩니다(같은 PC에서도 혼자 양쪽을 해 볼 수 있습니다).

## 아직 안 되는 것

폴더 잠그기. 휴대폰에서 허락하기. 받는 사람이 설치 없이 열기.
